## E-commerce website (NerdyGadgets)

### Projectomschrijving

Deze repository bevat een e-commercewebsite ontwikkeld voor *NerdyGadgets*, een fictief technologiebedrijf. Het project richt zich op het ontwerpen en bouwen van een volledige webshop met kernfunctionaliteiten voor productbeheer, bestellingen en gebruikersinteractie, inclusief aandacht voor beveiliging.

### Functionaliteiten

* Homepagina
* Productoverzichtpagina
* Zoek- en filterfunctionaliteit
* Productdetailpagina
* Winkelwagen
* Besteloverzichtpagina
* Inlogpagina
* Accountoverzichtpagina
* Reviews plaatsen voor producten
* Reviews plaatsen voor NerdyGadgets
* Contactpagina

### Technische details

* Frontend: HTML, CSS
* Backend: PHP
* Database: MySQL
* Databasekoppeling via SQL
* Volledige CRUD-functionaliteit voor producten, gebruikers en reviews
